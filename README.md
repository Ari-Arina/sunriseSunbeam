# Sunrise Beach Vacation
### Sunrise Sunbeam HTML, CSS, and JS Basic Tutorial


A blog website of my vacation happening a few weeks before Sunbeam following the Sunbeam Sunrise tutorial!

The video I used is [here](https://www.youtube.com/watch?v=8epYhLwQcbw), while I used the [CSS Flexbox Guide by Chris Coyier](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) to help me on the website more!

Two google fonts were also used: 
1. [Rubik Bubbles](https://fonts.google.com/specimen/Rubik+Bubbles)
2. [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque)
